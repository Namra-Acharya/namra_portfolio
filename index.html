05 machine learning workflow

A disciplined approach to machine learning

  1. 01

    DATA

    Load and inspect — shape, types, missingness, distributions.

  2. 02

    CLEAN

    Handle missing values, outliers, and inconsistent types.

  3. 03

    EXPLORE

    Understand structure, target relationships, and drift risk.

  4. 04

    ENGINEER

    Build features and transformations deliberately — no leakage.

  5. 05

    TRAIN

    Fit models on train folds only; stratify when classes are imbalanced.

  6. 06

    VALIDATE

    Cross-validate and tune without touching the test set.

  7. 07

    EVALUATE

    Report fit-for-purpose metrics and compare baselines honestly.

engineering constraints

  • Data qualityA pipeline is only as trustworthy as its inputs.
  • Feature engineeringDomain-informed features matter more than model tweaks.
  • Leakage preventionEvery transformation is fitted on train data only.
  • Proper validationCross-validation that mirrors real deployment.
  • Evaluation metricsMetrics chosen for the decision being made.
  • ReproducibilitySeeded runs, versioned data, documented steps.
